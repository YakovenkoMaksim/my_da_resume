ЯКОВЕНКО МАКСИМ

DATA ANALYST (Аналітик даних)

Аналітик даних, який перетворює складні дані на зрозумілі та корисні відкриття.

Мої навички Power BI, SQL, Tableau, Looker Data Studio, Excel та інших інструментів дозволяють мені ефективно аналізувати дані та виявляти тенденції, які допомагають бізнесу приймати обґрунтовані рішення та досягати успіху.

Я завжди прагну доводити завдання до кінця, звертаючи увагу на деталі та дотримуючись термінів.

Моя мета - забезпечити ваш бізнес цінною інформацією, яка допоможе йому зростати та розвиватися.

РОЗРОБНИК POWER BI (АНАЛІТИК ДАНИХ)

Агенція оборонних закупівель ДОТ (Оборонно-промисловий комплекс)

ОБОВ'ЯЗКИ:

  • Налаштування RLS та безпеки: Впровадив та адміністрував рольову модель доступу (Row-Level Security / RLS) і групи користувачів для розмежування прав перегляду конфідеційних даних між відділами.
  • Робота з Power BI Service / PBI RS: Налаштовував публікацію звітів, розклади оновлення даних (Data Refresh), роботу з Data Gateways, а також керував робочими просторами (Workspaces).
  • Написання DAX-мір: Розробляв оптимізовані DAX-формули та міри (Time Intelligence, Dynamic RLS, накопичувальні підсумки) для гнучкого аналізу бізнес-показників у різних розрізах.
  • Оптимізація продуктивності: Проводив аудит та оптимізацію швидкодії дашбордів (Performance Analyzer, зниження навантаження на пам'ять, оптимізація DAX та моделей даних).
  • Проєктування моделей даних: Будував ефективні реляційні та аналітичні моделі даних (схема «Зірка» / «Сніжинка»), трансформуючи сирі дані у зручні вітрини для швидкої аналітики.
  • Аналіз даних з ERP-систем: Створював управлінську, фінансову та операційну звітність на основі даних з ERP-систем, забезпечуючи наскрізну аналітику від закупівлі до складських залишків.
  • Високий рівень SQL & EDA: Використовував складні SQL-запити (CTE, віконні функції, складні JOINs, підзапити) в MS SQL та PostgreSQL для дослідження джерел (EDA), валідації цілісності даних та формування вітрин даних.
  • ETL/ELT та очищення даних: Налаштовував процеси трансформації даних в Power Query та на рівні SQL для автоматизації оновлень та забезпечення високої якості даних (Data Quality).

ПРОЄКТИ

Аналіз продажів магазину іграшок в PowerBI

Інтерактивний мультивалютний звіт Power BI для аналізу продажів мережі магазинів дитячих іграшок.

Технічні аспекти:
Джерела даних: Імпорт даних з SQL Server, Excel, API курсів
Очищення та трансформація даних в Power Query.
Модель даних: Створення реляційної моделі. DAX міри для KPI (загальний обсяг продажів, середній чек, конвертація валют).
Мультивалютність: Конвертація валют "на льоту" за допомогою DAX та таблиці курсів.
Інтерактивність: Фільтри, зрізи, drill-down/drill-through.
Результат: Інтерактивний звіт для аналізу продажів, відстеження KPI, виявлення тенденцій та порівняння ефективності.
